# Daily Boarding Call — Interview Practice

A daily interview-practice tool: random cabin-crew interview question, a 90-second timer, camera recording (stays on your device — nothing is uploaded), a self-check list, and a streak tracker.

## How to put this on GitHub Pages (once, ~5 minutes)

1. Go to [github.com](https://github.com) and log in (or create a free account).
2. Click the **+** icon top-right → **New repository**.
3. Name it something like `boarding-call` → set it to **Public** → click **Create repository**.
4. On the new repo page, click **Add file → Upload files**.
5. Upload the `index.html` file from this folder.
6. Click **Commit changes**.
7. Go to the repo's **Settings** tab → **Pages** (left sidebar).
8. Under "Build and deployment", set **Source** to **Deploy from a branch**, branch = `main`, folder = `/ (root)` → **Save**.
9. Wait about a minute, then refresh — GitHub will show you a live URL like:
   `https://yourusername.github.io/boarding-call/`

That URL works on your phone and laptop, and your browser will ask for camera/microphone permission the first time you click "Enable camera" — just allow it.

## Notes
- Recordings save as `.webm` video files directly to your device via the Download button — nothing is stored online or sent anywhere.
- Your streak is saved in your browser only (not synced across devices).
- To update the tool later, just re-upload `index.html` to the same repo.
